How one number is made

How long is crack-1?

  1. SAM 3.1 masks the crack 24,800 px of mask
  2. Thin the mask to a one-pixel skeleton, count its length 913 px
  3. The coin is 27 mm across and 287 px wide in the same plane 0.094077 mm/px
  4. Multiply 913 × 0.094077 = 85.9 mm

No language model touches the arithmetic. The writer only receives the results, and every result arrives with an id.

Thresholds are printed in every report: cosmetic ≤ 1 %, moderate ≤ 5 %, significant above that, or a crack ≥ 150 mm, or 3+ regions. Confidence on R004 is the mask's 0.88 times the coin's 0.88.

The evidence gate

The crack covers 5.17% of the panel R002, runs 85.9 mm R004 and is classed significant R005.

The crack is about 12 cm long. R002

Muse Spark 1.3 writes the findings. Each sentence has to cite receipts, and every number in it has to match one of them. The second sentence cites R002, which says 5.17 %, not 12, and it uses a unit the engine never emits. The build stops:

EvidenceError: Evidence gate failed:
- finding[1]: number 12 is not backed by any cited receipt
- finding[1]: statement uses a unit this engine never emits
  (use mm or %): "The crack is about 12 cm long."

The skeptic

Spark Open, open weights on Baseten, gets the same receipts and the written findings, and nothing else. It re-derives each claim. Anything it cannot reproduce is printed as disputed in the report, next to the claim, never removed.

crack-1 runs 85.9 mm R004 reproduced
stain-1 is moderate R008 DISPUTED no calibrated length; two regions of 1.29 % may be one patch

Illustrative verdicts. The skeptic call is being wired live this week.

Refuse rather than guess

When the coin is half covered, its outline no longer fits a circle. Confidence drops below the 0.60 floor, the scale is rejected with its own receipt, and the report falls back to percentages. Millimetres are printed as empty, not estimated.

Four Meta models, four jobs

  1. Muse Voice TranscribeTurns the spoken line into text. Hindi, Telugu, Hinglish.
  2. SAM 3.1Masks the damage and the coin. Pixels only, no opinions.
  3. Plain codeArea, skeleton length, scale, severity. Every result becomes a receipt.
  4. Muse Spark 1.3Writes the findings. Cites receipts or the build fails.
  5. Spark OpenRe-checks the findings independently. Disagreement is printed.

No image generation anywhere. Every visual in the report is drawn in code from the masks and the math.

Replay it yourself

Every number on this page comes from the engine running on a fixture in the repo. Clone it and the tests recompute them, offline, without spending a cent on API calls.

cd snapclaim
npm install
npm test
